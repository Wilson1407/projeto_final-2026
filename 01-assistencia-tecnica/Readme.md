Projeto Assistência — Web Design
Como foi realizar o projeto de assistência técnica?

Realizar o site sobre assistência técnica foi uma experiência incrível, tanto para mim quanto para meus colegas. Durante o desenvolvimento do projeto, aprendemos coisas novas e também reforçamos conhecimentos de programação que já tínhamos.

Foi uma ótima atividade para nosso aperfeiçoamento como futuros programadores, pois tivemos a oportunidade de colocar nossos conhecimentos em prática e entender melhor como pode ser o trabalho dentro de uma empresa, principalmente quando realizado em equipe.

Quais foram as dificuldades encontradas durante o desenvolvimento do código?

Durante a realização do projeto, encontramos algumas dificuldades, principalmente em relação à implementação e organização do site. Os principais desafios foram:

Implementação do QR Code para pagamentos;
Fazer a barra de pesquisa funcionar corretamente;
Organizar o layout de toda a página, garantindo uma boa estrutura visual;
Desenvolver e implementar um chatbot de atendimento.

Apesar das dificuldades, conseguimos trabalhar em equipe para encontrar soluções e melhorar o funcionamento do projeto.
